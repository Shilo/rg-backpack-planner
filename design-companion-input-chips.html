InputChip Design Exploration

Six approaches for unified combo chips that represent keyboard, mouse, and touch inputs as single cohesive units — no / separators between alternatives. Each approach trades off density, clarity, and visual hierarchy differently.

A. Segmented Pill (Current KbdChip)

Baseline

What you already have. The combo is one pill with a faint "+" glyph between segments. Modifiers are slightly dimmed. Clean and functional.

Strengths
Clean, minimal, already proven. Each chip reads as one unit. "+" glyph is familiar.
Weaknesses
The "+" glyph inside the pill can still read as two things. No visual hierarchy between modifier and action.

B. Inset Divider

Recommended

Same pill, but a thin inset border replaces the "+" glyph. Segments become visual compartments. Reads like a single component with labeled sections — like a segmented control.

Strengths
The divider reads as "part of the same thing" (like Ctrl|Z) without needing a "+" symbol. Excellent scannability. Each pill is clearly one atomic unit. Scales to 3-part combos cleanly.
Weaknesses
Slightly heavier visual weight than A. The divider line adds a small amount of visual noise.

C. Gradient Modifier Zone

Subtle

Modifier segments get a darker background that blends into the action segment. No dividers, no "+". The background shift alone signals "modifier → action" flow.

Strengths
Very smooth, unified feel. The background shift provides subtle hierarchy without any separators. Lightest visual weight of all combo approaches.
Weaknesses
The background difference is subtle — may not be noticeable enough in all themes. The "›" chevron is unusual for shortcuts.

D. Accent-Tinted Modifier

Expressive

Modifier segments pick up a hint of the theme's accent color, with an accent-tinted divider. Creates a clear "modifier zone" vs "action zone" within the pill.

Strengths
Strong visual hierarchy — modifiers are immediately identifiable. Ties into the theme's accent, so it feels native. The accent divider is a nice micro-detail.
Weaknesses
Busiest option. May fight for attention with surrounding UI. The accent tint adds color complexity that could clash with dense shortcut lists.

E. Compact Prefix Notation

Dense

Modifiers render as smaller, lighter prefix text within one pill. No dividers or extra elements — just typography hierarchy. Most space-efficient.

Most compact. Great for dense UIs or tooltip contexts. Typography alone creates hierarchy.

Less visually distinct combos — modifier and action can blur together. Harder to scan quickly in a long list.

F. Input-Type Color Coding

Semantic

Each chip gets a subtle tint based on input type: blue for keyboard, green for mouse, amber for touch. Combined with inset dividers. You instantly know which device a shortcut is for.

Strengths
Maximum information density — input type is instantly readable. Works beautifully for a controls/settings page where all three input types appear together.
Weaknesses
Most complex to implement (requires knowing the input type). The color-coding system needs to be learned. May add too many colors to an already themed UI.

Design recommendation: Approach B (Inset Divider) is the strongest default — it's the clearest visual signal that segments belong to one combo, without adding color complexity or unusual symbols. It pairs well with approach F's color coding as an optional enhancement if you want to differentiate input types on the controls page. Approaches can also be mixed: B's divider structure with D's accent tint for the modifier zone, for example.
