# App Store Changelog skill

Generate user-facing App Store release notes from git history (since last tag or a given ref). Adapted from [Dimillian/Skills app-store-changelog](https://github.com/Dimillian/Skills/tree/main/app-store-changelog).

All project skills live in `.skills/` at repo root. Scripts and reference docs are in this folder.

**Usage:** Ask the AI to generate release notes, a changelog, or "What's New" text; it will use this skill to collect changes and draft store-ready bullets.
