Unique Node Differentiation — All Approaches

Each tree type has 6 unique "class identity" nodes (e.g. Stun, Pierce Resistance for Guardian). These should be visually distinct from common nodes (Atk Boost, HP Boost, etc.) but NOT outshine the hexagon leaf node. Open this file in a browser to preview.
